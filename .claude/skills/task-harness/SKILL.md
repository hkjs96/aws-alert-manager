# 작업 하네스

## 읽을 것

`docs/AGENT-HARNESS-GUIDE.md` — 스프린트 계약 체크리스트, Evaluator 체크리스트,
복구 규칙, 보고 포맷이 모두 여기 있다. 이 스킬은 그 내용을 복사하지 않는다.

## 착수 시

계약을 먼저 정한다: 바꿀 파일/영역, **바꾸지 않을 영역**, 보존할 기존 동작, 핵심 불변식,
RED 단계의 예상 실패, GREEN 단계의 검증 명령, 전체 회귀 명령(`python scripts/verify_all.py`).

## 완료 주장 직전

Evaluator 체크리스트를 통과시킨다. 특히:

- 검증 **명령과 그 출력**을 근거로 제시한다 — "동작할 것이다"는 근거가 아니다.
- `git diff --name-only`와 `git diff --stat`으로 계약 밖 파일이 섞이지 않았는지 본다.
- 테스트가 실패했으면 실패했다고 보고한다. 스텁·TODO를 남긴 채 완료라고 하지 않는다.
- 배포까지 갔다면 실제 실행 로그를 확인한다 — `premortem-deploy` 2항(조용한 실패) 참조.
- 남은 리스크를 명시한다.

## 복구

같은 방법이 두 번 실패하면 방법을 바꾼다. 같은 버그가 재발하면 편집 전에 소스 경로를
깊게 본다. 스코프가 커지면 멈추고 사용자에게 재확인한다.
